## 二、怎么用（3 种方式，选一个）

### 方式 1：直接找豆包（推荐，最省事）
直接说需求，不用提任何名字，例如：
- "做一条端午包粽子的古风视频，竖屏 20 秒，出分镜"
- "写一张宋式闺阁少女的图片提示词，中英双语"
- "搜一下画质净化段落，我要让画面干净"

- 该技能已经装在电脑 6 个位置（豆包 / .agents / .codex / Doubao / .claude），哪个工具都能调

### 方式 3：自己翻主文档抄词

## 四、最简调用流程（3 步走）

1. **定题材** → 想拍什么：节日（春节/端午/七夕/中秋…）、生活（点茶/梳妆/读书/洗衣…）、仪式（婚嫁/祭祀/成人礼…）、仙侠（云海/巨殿/飞升…）
2. **定规格** → 图片 or 视频？视频多长？（15s / 30s / 1min+）竖屏 9:16 or 横屏 16:9？
3. **让 AI 干活** → 在豆包说需求；素材拼装照第三节的编号表；完整案例照抄 CASE 改词

示例一句话指令：
> "用 WCF 技能做一条『中秋拜月』30 秒竖屏视频，先出分镜再出首帧图，中英双语。"

---

## 五、三大铁律（改词时别犯）

1. **字幕/文字卡/含文字的物体一律不进生成画面**（婚书、对联、招牌这类 90% 会乱码），后期剪辑再加字幕
2. **交付中英双语**（英文喂 GPT Image / MJ 等国外工具）
3. **入库只存中文**（英文只在交付时给，不写进库）
